# Packaging assets

`verdite2.png` and `verdite2.ico` are **placeholders**, generated by
`packaging/shared/make-icon.py` in the palette the game's own map uses (field
`#3A523A`, ink `#0E200E`, bevel `#7B8C7F`). They exist so the AppImage and the
Windows build have something to reference; they are not artwork and should be
replaced before a release anyone else sees.

Replacing them needs nothing but overwriting the two files at the same sizes:
256x256 for the PNG, and a multi-size ICO (16/32/48/256) for Windows.
